# AGENTS.md (archive)

Instructions for AI coding agents working under `docs/archive/`.

## Purpose

This directory holds **historical** agent-oriented documentation preserved unchanged when instructions moved to root `AGENTS.md`. It is not the canonical source for build, layout, or workflow guidance.

## Boundaries

- **Do not modify files here** when updating agent instructions for this repository. Put current instructions in root `AGENTS.md`.
- Do not read or update `copilot-instructions.md` or `agents-before-init.md` in this directory.
- To promote deferred notes into active instructions, edit [agent-deferred-notes.md](agent-deferred-notes.md) deliberately. Do not sync other archived files to match the current project state.
